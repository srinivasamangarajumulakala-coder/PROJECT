# VoteConnect React + Vite Project

## Run the project
1. Extract this ZIP file.
2. Open the `VoteConnect-React` folder in VS Code.
3. Open Terminal > New Terminal.
4. Run these commands:

```bash
npm install
npm run dev
```

5. Open the localhost URL shown in the terminal (usually http://localhost:5173).

## Demo admin login

## Voter flow
- Sign up with age 18 or above.
- Log in with the registered email and password.
- Open the dashboard and cast one vote.
- Check Results.
- Admin dashboard shows registered voters and vote records.

## Important
This is an academic demonstration using browser Local Storage. It is not secure enough for real elections. Data is stored only in the browser where the app is used.
